# OFFNet

This is the official PyTorch implement of the paper: OFFNet: Omni-Frequency Filtering for Single-Image Super-Resolution

Clone this github repo:

```
https://github.com/EasyVision-Ton/OFFNet.git
cd OFFNet
```

The benchmarks include Set5, Set14, B100, Urban100, and Manga109 (the full datasets can be downloaded by click [there](https://drive.google.com/file/d/1yMbItvFKVaCT93yPWmlP3883XtJ-wSee/view)).

This work is based on [KAIR](https://github.com/cszn/KAIR), which is an awesome project.
