## FreqSR (CVIU-2026)
This is the official repository for the [paper](https://www.sciencedirect.com/science/article/abs/pii/S1077314226003498) FreqSR.

## Train
We train our model on the [DIV2K](https://data.vision.ee.ethz.ch/cvl/DIV2K/) dataset.

## Test
The benchmarks include Set5, Set14, B100, Urban100, and Manga109 (the full datasets can be downloaded by click [here](https://drive.google.com/file/d/1yMbItvFKVaCT93yPWmlP3883XtJ-wSee/view)).
